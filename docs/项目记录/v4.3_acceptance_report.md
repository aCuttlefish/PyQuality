## 浏览器完整操作

在 `http://127.0.0.1:8000/acceptance.html` 实际操作：

1. 加载元音统计示例，核对七个预期值、确认标准，执行错误实现。
2. 报告显示 FAIL、4/7 通过，展示大写遗漏的实际返回值与提示词改写。
3. 点击“换入示例正确实现”，复用标准，得到 PASS_WITHIN_SCOPE、7/7。
4. 点击“生成验收标准”，真实模型提取四条必要需求及九个案例。
5. 编辑模型的措辞/输入域说明，核对各案例预期，补充一个非 ASCII 字符边界案例；
   明确确认以固定案例为范围。
6. 错误实现 9/10，通过大多数测试仍因大写元音反例判 FAIL。
7. 换入正确实现，报告显示相同标准从 9/10 改善到 10/10，
   四项需求均在检查范围内通过、静态可读性评分 100/A。
