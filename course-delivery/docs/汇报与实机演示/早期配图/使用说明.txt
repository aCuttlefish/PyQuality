PyQuality 汇报配图交付说明

文件布局
  图片清单.html   离线浏览、按章节或图名查找，打开原图和矢量文件
  图片清单.txt    完整图片列表、用途、讲述重点和参考页码
  png/            28 张高清 PNG，3200 × 1800
  svg/            28 张 SVG 矢量图
  preview/        4 张缩略总览，便于快速挑选
  data/           图片清单 JSON、实测数据快照及来源
  source/         绘图、导出和布局检查脚本

在 PowerPoint / WPS 中使用
  1. 插入 → 图片 → 此设备，选择 png 中的图片，保持原比例。
  2. 图片统一为 16:9。可以整幅使用，也可以在 PPT 中裁去题头和页脚，只保留主体图。
  3. 需要无损放大或修改文字时使用 SVG。具体的形状转换能力取决于 Office / WPS 版本。
  4. 案例图的百分比仅为对应固定测试通过比例，不应改写成总体检测准确率。

内容依据
  参考 PDF 用于确定汇报章节和图示类型。系统架构、接口、数据模型及存储位置来自当前代码。
  所有案例数字来自仓库中的 summary.json 和原始执行报告。图片没有采用参考材料中的完成度百分比。
  相关回归检查的 62 项通过是已留存的指定测试范围，不能当作全仓测试总数。

复现图片
  需要 Node.js、sharp、Python、Pillow，以及 Microsoft YaHei 中文字体。
  本次已使用 Codex 随附运行时完成渲染和检查。data/evidence_snapshot.json 保留绘图输入。
  运行 node source/build_figures.js 生成 PNG、SVG 和清单数据。
  运行 python source/check_layout.py 进行文字几何检查并生成缩略图。
  运行 python source/build_catalog.py 重新生成浏览页与文字清单。
  若原仓库不可见，绘图脚本会使用数据快照；PYQUALITY_REPO 可指定本地仓库位置。
