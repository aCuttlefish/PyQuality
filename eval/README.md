# PyQuality 评测与证据

| 目录 | 验证内容 | 证据 |
| --- | --- | --- |
| `real_cases/` | 电商满减和通讯录去重，合计 **20 条**最终固定评测。 | 场景需求、确认计划、原提示词、改写、模型原始响应、初始和再生成代码、两轮报告。 |
| `workflow/` | 范围限制、保留重复元素排序、元音统计的历史实测，以及容器隔离和超时记录。 | 每组原实现/修正版报告、`summary.json` 和 `isolation.json`。 |
| `docker_replay/` | 五个内置样例的课程交付复跑。 | Docker 实际执行报告和汇总；不调用模型，建议来源为规则降级。 |
| `public_case/`、`public_cases/` | 公开源码案例，包括 BMI、扑克牌和零项枚举。 | 公开版本与来源记录、适配器、固定标准及人工修改前后的报告。 |

电商满减的最终计划包含 11 条，初始实现 10 条通过、再生成实现 11 条通过。通讯录去重的最终计划包含 9 条，初始实现 5 条通过、再生成实现 9 条通过。每组前后计划摘要一致。初筛阶段的电商 10 条计划与最终 11 条计划分别保存，正式比较使用后者。业务数据由课设实验构造。

逐项输入、预期、前后实际结果、证据编号及模型使用记录见 [过程作业 2](../docs/过程作业/作业2/评测集与AI使用日志.md)。复跑入口见[主说明](../README.md)。报告中的历史本机路径是当时的运行元数据，交付目录内的 JSON、源码和脚本用于复查及复跑。
